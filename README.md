# Knowledge-Neuron World Model (KNWM)

**Independent Research Project | Qinzheng Hu**

**Paper Status: Under Review at ICLR 2027**

## Overview

KNWM (Knowledge-Neuron World Model) is a world model that I independently designed and developed.

The goal of KNWM is to enable AI systems to learn, organize, and reuse knowledge across different domains, particularly physics, mathematics, and computer science.

Unlike approaches that rely mainly on language models for reasoning, KNWM uses a structured knowledge-neuron architecture to support knowledge learning, memory, logical reasoning, complex problem-solving, physical prediction, and autonomous planning.

## Key Features

**1. Knowledge-Neuron Architecture**

KNWM organizes learned knowledge into structured knowledge neurons.

I designed an architecture that connects these neurons through recursive structures, layered memory, and shared knowledge elements.

The system includes three main functional types:

- Scientific Knowledge Neurons
- Event Knowledge Neurons
- Problem Knowledge Neurons

These neurons allow KNWM to activate, combine, and reuse knowledge when solving different problems.

**2. Autonomous Knowledge Learning**

KNWM can discover scientific relationships through observations and experiments, validate them, and store the learned knowledge for future use.

**3. Reasoning and Complex Problem-Solving**

KNWM can use accumulated mathematical and physical knowledge to perform calculations, combine multiple knowledge relationships, and solve multi-step problems.

**4. Autonomous Planning**

KNWM uses its existing knowledge to generate and evaluate possible plans. It can also revise plans based on environmental feedback.

**5. Autonomous Capability Expansion**

I have also developed an initial AGI-oriented system combining KNWM with an LLM.

In this system, KNWM handles knowledge, memory, reasoning, and planning, while the LLM mainly handles language input and output.

The system has initial capabilities to develop, test, and retain new reusable tools through knowledge-driven planning and coding.
